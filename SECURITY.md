# Reporte de problemas de seguridad

No incluyas datos de comidas reales, respaldos o información personal en issues públicos ni en commits.

Para reportar un problema:
1. Describe la versión y el navegador afectados.
2. Explica pasos de reproducción sin usar datos personales.
3. Indica el impacto observado y una posible mitigación.
4. Si el problema expone datos privados, evita publicar detalles explotables hasta acordar una forma de revisión privada con el mantenedor.

YEXCEL actualmente no tiene autenticación ni un backend. El almacenamiento local no protege los datos frente a otras personas que tengan acceso al mismo perfil de navegador.
