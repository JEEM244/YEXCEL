# Preguntas pendientes para el cliente

Antes de convertir el prototipo en la versión final, confirmar:

1. ¿Qué columnas exactas debe tener el archivo de Excel?
2. ¿El cliente entregará una plantilla existente?
3. ¿Cada día debe ser una hoja, una fila o una sección?
4. ¿Es necesario importar información desde Excel o CSV?
5. ¿Se usará solo en una computadora o se necesita sincronizar datos?
6. ¿Varias personas usarán la app?
7. ¿Los registros deben editarse después de guardarlos?
8. ¿Qué campos son obligatorios?
9. ¿Se necesita contraseña o control de acceso?
10. ¿Qué formato regional de fecha y separador decimal debe utilizarse?

Las respuestas definen el alcance real; por ahora no se simula una base de datos ni se promete sincronización.
