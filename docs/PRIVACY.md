# Privacidad y almacenamiento

- Los registros de esta versión se guardan en el almacenamiento local del navegador.
- No existe inicio de sesión ni sincronización entre dispositivos.
- Cualquier persona con acceso al mismo perfil de navegador podría ver los datos.
- Borrar datos del sitio o cambiar de navegador puede hacer que los registros dejen de estar disponibles.
- Los respaldos exportados contienen los datos legibles del usuario; deben guardarse en un lugar privado.
- La aplicación no debe indicar que los datos están respaldados automáticamente.
- Si el navegador bloquea el almacenamiento, la interfaz debe informar del problema en lugar de afirmar que guardó correctamente.

Este documento describe el prototipo actual y no sustituye una revisión de privacidad para un despliegue con cuentas o información sensible.
