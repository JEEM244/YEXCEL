# Accesibilidad a revisar

- Los controles deben tener etiquetas visibles o nombres accesibles.
- El orden de tabulación debe seguir el orden visual.
- Los mensajes de guardado o error deben anunciarse con una región viva.
- Los iconos decorativos no deben ser el único nombre de un botón.
- El modal debe poder cerrarse con Escape y devolver el foco al control que lo abrió.
- Debe respetarse `prefers-reduced-motion`.
- Contraste de texto, foco visible y lectura en pantalla pequeña deben probarse manualmente.
