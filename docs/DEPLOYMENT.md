# Despliegue

La app es estática y puede publicarse en un host que sirva HTML, CSS y JavaScript. GitHub Pages puede servirla desde la raíz de la rama configurada, si se habilita en los ajustes del repositorio.

Antes de publicar:
- Confirma si los registros del cliente son apropiados para almacenarse en el navegador.
- Prueba rutas de los recursos y que el sitio funcione desde una subruta.
- GitHub Pages hace pública la interfaz; no convierte localStorage en almacenamiento privado o sincronizado.
- No subas respaldos reales al repositorio.
- No afirmes que el sitio está desplegado hasta comprobar una URL publicada.
