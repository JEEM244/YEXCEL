# Entrega de formato Excel

La implementación final debe basarse en un archivo de ejemplo proporcionado por el cliente, no en encabezados adivinados.

Al recibirlo, revisar:
- Nombres y orden exactos de las columnas.
- Hojas, filas de encabezado y celdas combinadas.
- Formatos de fecha y hora.
- Si el cliente requiere CSV o un archivo real XLSX.
- Si hay fórmulas o validación de datos que deban conservarse.
- Si los registros existentes deben migrarse al nuevo esquema.

Probar el archivo generado abriéndolo con Excel y comparando el resultado con la plantilla original.
