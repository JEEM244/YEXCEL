# Guía de cambios

- Mantén la interfaz en español y el tono visual oscuro con acentos azules.
- Evita dependencias en tiempo de ejecución para una app estática sencilla.
- Coloca transformaciones de datos en módulos independientes del DOM.
- Añade pruebas con `node --test` cuando cambies validación, almacenamiento o exportación.
- Nunca registres ni confirmes claves, datos personales o respaldos reales.
- Actualiza el README o la documentación específica cuando cambie el comportamiento visible.
