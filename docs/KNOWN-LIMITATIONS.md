# Limitaciones conocidas

1. El almacenamiento es local al navegador; no hay sincronización, cuentas ni recuperación del lado servidor.
2. CSV es un formato de intercambio, no un libro Excel `.xlsx` con varias hojas.
3. Los encabezados actuales son provisionales.
4. Todavía no existe importación desde una plantilla XLSX del cliente.
5. Las pruebas automáticas cubren funciones de datos, pero no sustituyen una prueba visual en navegador.
6. No debe almacenarse información especialmente sensible sin definir medidas de seguridad adecuadas.
