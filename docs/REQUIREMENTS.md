# Requisitos provisionalmente aceptados

## Confirmado para el prototipo
- Uso principal en computadora, con adaptación básica a pantalla pequeña.
- Registro manual de comidas por fecha.
- Consulta de historial y búsqueda básica.
- Interfaz seria en negro y azul.
- Exportación de datos para abrir en Excel.

## Provisional y pendiente de validación
- Campos exactos del registro.
- Encabezados, orden de columnas, formato y hojas de Excel.
- Necesidad de importar datos desde archivos.
- Si se requiere un archivo XLSX real.
- Necesidad de cuentas, permisos o uso simultáneo por varias personas.
- Política de respaldo y conservación de datos.

La aplicación no debe confundirse con una herramienta de diagnóstico o recomendación nutricional; únicamente organiza datos introducidos por el usuario.
