# Hoja de ruta

## Completado en esta etapa
- Separación de HTML, CSS y JavaScript.
- Módulos de utilidades, almacenamiento y exportación.
- Validación de registros y migración desde la clave local anterior.
- Edición, eliminación y filtros por fecha.
- Exportación CSV y respaldo JSON versionado.
- Pruebas unitarias y flujo de CI.
- Documentación de privacidad y límites.

## Siguientes prioridades
1. Ejecutar las pruebas en CI y corregir los defectos detectados.
2. Probar el flujo completo en navegadores de escritorio y móvil.
3. Obtener la plantilla real de Excel y adaptar exportación e importación.
4. Decidir con el cliente si necesita cuentas, sincronización o almacenamiento en servidor.
5. Evaluar accesibilidad con teclado y lector de pantalla.
6. Confirmar requisitos de publicación y respaldo.

No iniciar sincronización o autenticación hasta que el cliente confirme que lo necesita; implican infraestructura y consideraciones de seguridad adicionales.
