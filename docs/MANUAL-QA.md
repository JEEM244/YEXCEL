# Pruebas manuales del prototipo

Completar con un navegador real antes de entregar:

- [ ] Abrir index.html y recorrer las cuatro vistas.
- [ ] Guardar desayuno, comida y cena en fechas diferentes.
- [ ] Editar una comida y confirmar que no crea un duplicado.
- [ ] Eliminar una comida y confirmar el aviso.
- [ ] Navegar al mes anterior/siguiente y seleccionar fechas de ambos meses.
- [ ] Filtrar por tipo, texto, fecha inicial y fecha final.
- [ ] Probar un rango inicial posterior a la fecha final.
- [ ] Descargar CSV y abrirlo en Excel con acentos y comillas.
- [ ] Probar textos que comienzan con =, +, - y @ en exportación.
- [ ] Descargar respaldo JSON, borrar/aislar datos de prueba y restaurar el archivo.
- [ ] Intentar restaurar JSON dañado y verificar que los datos no cambian.
- [ ] Navegar el formulario con Tab, Shift+Tab y Escape.
- [ ] Probar vista estrecha y preferencia de movimiento reducido.
- [ ] Bloquear almacenamiento en navegador y verificar que no se anuncie un guardado falso.
